# PhaseEQ v2.0.4 更新案内

PhaseEQ v2.0.4では、miniDSP向けのファイル生成を独立モジュールへ分離しました。単体EQと2つのマルチウェイ出力経路について、既存の操作、係数、適用順序、ファイル名・形式を維持しています。C-DSP専用出力の互換入口も保持します。

## Device Consoleへの読み込み

`2x4 HD (48kHz)`は48 kHz、`2x4 HD`は96 kHzで生成してください。PhaseEQの`miniDSP`ボタンからTXTを保存し、Device Consoleの対象チャンネルで`PEQ → Menu ON → LOAD BIQUADS FILE`を選びます。マルチウェイではZIP内の係数ファイルと経路・設定情報を使用します。

- PEQは1ブロック10段です。HP／LPやAPプリセットは複数段になる場合があります。TXTの`biquad`段数を確認してください。
- 10段を超えるファイルはConsole側で先頭10段のみ読み込まれます。汎用miniDSP出力は機種専用の10段制限と連動しないため、対象ブロックへ収まることを確認してください。
- 10段未満では残りのEQが保持されます。読み込み後は不要な段の無効化も確認してください。
- 別ファイルを同じPEQブロックへ続けて読み込むとEQ1から上書きされます。各ファイルの配置先はZIP内の経路情報に従ってください。

詳しい対応形式と制限は[出力ファイル仕様](output-format.md#minidsp-device-consoleへの読み込み)を参照してください。

## 確認した範囲

Device Console 1.2.5の48／96 kHz両オフラインテンプレートで、計6ファイルを読み込みました。PEQ、Shelf、通常／反転1次AP、2次AP、4次HP／LPを含む計46段・230係数について、Consoleから保存した値が元TXTをfloat32へ丸めた値と一致しました。

移設前後の計70ファイルのバイト一致と、隔離したPhaseEQの日英画面からの48／96 kHz実ダウンロードを確認しました。軽量品質チェックは3995件成功、4件skip、5 subtests成功です。実機への送信、音声処理、音響測定、FIR読み込みは今回の確認に含みません。実機へ適用する前に、対象モデル、動作サンプルレート、使用するプリセットを確認してください。

## 更新

作業設定を保存し、[インストールガイド](installation.md)に従って更新してください。更新後はPhaseEQを再起動してください。
