# PhaseEQ v2.0.11 更新案内

PhaseEQ v2.0.11では、マルチウェイ構成から測定計画を作成し、左右それぞれで基準ツイーターから各ウェイへ進むマイク測定を追加しました。測定機能はFree／Proで共通です。使用できるマルチウェイ構成は各版の対応範囲に従います。

## 構成から測定・保存・割り当てへ進む

マルチウェイで構成を保存し、「この構成をマイク測定」から各ウェイの実出力経路、基準、測定目的、FRD保存先を設定します。マイク位置を確認して「今回の測定を準備」を押し、既存の詳細測定で入力機器、校正、ゲイン、保護条件を確認して収録します。

同じESS収録から周波数特性と基準に対する時間差を取得します。品質条件が成立すると収録を終了し、原本付きライブラリ記録とFRDを保存します。FRDはHz・dB・位相度の3列で、ファイル名は`先頭文字列_YYYYMMDD_HHMMSS.frd`です。ゲートあり／反射を含む応答を選べます。保存後は「次のウェイへ」「次の側の測定へ」で進み、対象ごとに保存結果をマルチウェイへ明示的に割り当てます。「調整後の確認」で取得した結果は補正入力へ割り当てません。

同じ側の測定中はマイクを固定します。2ウェイの1m基準ではウーファーとツイーターの中心を通る測定軸を使い、反射を確認してゲートを設定してください。左右を切り替えるときは基準点・距離・高さ・向きを揃えます。近接測定との合成は別途行います。

## 時間基準と出力経路

基準ツイーターの取得では基準マーカーとESSを同じ基準ユニットへ届け、その後はマーカー経路を固定してESSの対象だけを切り替えます。物理出力の切替と外部プレーヤーの停止は手動です。音源のL/Rとスピーカーの左/右を区別し、DAC端子同士を直結せず、プレーヤー・DSPでルーティングしてください。

測定計画と左右別の時間基準処理を独立モジュール化し、既存の収録・解析・キャッシュ・受け渡しを再利用しました。各側のユニット間ディレイは既存の位相・時間整合で明示適用します。左右スピーカー間の到達差は別測定です。共有SUBなど異なる基準をまたぐ構成では、共通時間基準を別途用意してください。FRD単体には時間基準の由来を引き継ぎません。

## 再開と復旧

同じ構成では保存した測定計画を明示的に再開できます。基準を測り直した側は後続ウェイも測り直します。構成が変わった場合は計画を作り直します。元の測定原本と既存割り当ては保持され、時間基準が混在した整合は拒否されます。FRD保存に失敗した場合は保存先を修正し、保存済み原本から再試行できます。

操作条件と復旧手順は[マルチウェイ構成からマイク測定する](multiway-microphone-measurement.md)を参照してください。既存の画像付き操作マニュアルはv2.0.10・改訂57の撮影内容を保持し、今回の新しい操作はこの手順書で補足します。

## 検証と実機での未確認事項

通常の軽量品質チェックは4,181件成功、4件スキップでした。隔離したChromiumで計画作成、位置確認、測定準備、終了・再開を確認し、合成した完了状態で次のウェイ・次の側への切替を確認しました。合成IRでは左右各2件の原本・FRD保存と、ゲート応答の再読込み一致を確認しました。これらの試験では実機収録を開始していません。

実機のLinux／Windows 11、UMIK-2のPGA・OS入力ゲイン・SPL精度、DAC/DSPの実配線と保護、時間差精度、ホールでの再生は未確認です。実演前に使用機材で基準取得、各ウェイ、左右切替、FRD保存・割り当て、ディレイ適用後の再測定を確認してください。実機受入れが完了していない構成では、事前確認済みのREW測定・読込みを使用してください。

作業設定を保存し、アプリを終了してから[インストールガイド](installation.md)に従って更新・再起動してください。
