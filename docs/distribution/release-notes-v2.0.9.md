# PhaseEQ v2.0.9 更新案内

PhaseEQ v2.0.9では、室内音響補正に測定から補正カーブを作る試用機能を追加しました。Free／Proの両版で利用できます。

## 測定から補正カーブを作る

`音の補正・フィルター設計 > 目標特性 > 室内音響補正（ルームEQ）`を開きます。既存カーブは`適用・保存`、基準と各席の測定から作る場合は`作成・評価（試用）`へ進みます。

基準1本と平均化前の各席のTXT／FRD／CSVを読み込み、レベル合わせ、空間平均、3帯域平滑化、補正帯域と上限を設定して生成します。既定はパワー平均、ブースト0dB、カット6dB、測定席の悪化上限1dBです。平均と各席の入力・補正後予測を比較し、生成カーブと条件・評価結果をJSONで保存できます。

生成だけでは適用しません。`生成カーブを補正欄へ読み込む`で現在のカーブを置き換えて加算・OFFとし、`適用・保存`で確認してONにします。その後、EQを更新・出力し、同じ席で再測定してください。既存の補正カーブJSONと、REWでカーブまで作る手順も利用できます。

## 切替と表示

設定復元後に届く古い入力欄の通知を世代で判別し、現在の補正を置き換えないようにしました。編集対象の切替要求は復元完了まで保持し、ページ操作による再実行で途中の要求が失われる経路を修正しました。

追加グラフは共通の配色と表示キャッシュを使用します。平均化前の各席を入力、生成カーブ加算後を補正後予測として表示します。平均化・補正処理は独立モジュールへ分離し、自動PEQと共用する平滑化処理の計算式を維持しています。

## 手順と確認範囲

画像付きの[室内音響補正マニュアル](room-eq.md)に、入力条件、生成、保存、明示読込み、再測定を記載しました。画像付き操作マニュアルは108ページ・改訂56へ更新しました。[年末例会の配布資料（3ページ）](manual/PhaseEQ_YearEndDemo_Handout_JA.pdf)は、UMIK-2・REWから4ch再生までの測定位置と復旧手順を更新しました。

補正後予測は生成カーブの理想加算です。実現IIR／FIRの応答や再測定結果とは区別してください。悪化制限は入力測点で評価します。ホールでの実測、実機再生、未測定席への効果は今回のソフトウェア検証に含めていません。

作業設定を保存し、アプリを終了してから[インストールガイド](installation.md)に従って更新・再起動してください。
