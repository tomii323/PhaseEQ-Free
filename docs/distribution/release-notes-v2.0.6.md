# PhaseEQ v2.0.6 更新案内

PhaseEQ v2.0.6では、メインターゲットを保持したまま、試聴位置による振幅の変化を独立して扱う「ルームEQ差分」を追加しました。Free／Proの両版で利用できます。

## 使用手順

1. `音の補正・フィルター設計 > 目標特性`を開き、メインターゲットを設定します。
2. `ルームEQ差分`で周波数・dBのTXT／FRD／CSV、または保存済みの専用JSONを読み込みます。テキストはOFFで読み込まれます。
3. 読み込んだ値が「試聴位置−基準」の変化量なら`減算`、「基準−試聴位置」の補正カーブなら`加算`を選びます。これは1m等の基準応答を設計入力に使う場合の符号です。
4. `ルームEQ差分を目標へ反映`でON/OFFを比較します。目標を変更した後は、必要なIIR／FIR EQを更新し、補正結果と出力を確認します。
5. `ルームEQ差分を保存`で曲線・ON/OFF・適用方法をJSONへ保存します。作業設定にも保存されます。メインターゲットの登録・応答ファイルへの出力には差分を含めません。

詳細は[ルームEQ差分の操作手順](room-eq.md)と[ユーザーガイド](user-guide.md#room-eq-delta)を参照してください。画像付きマニュアルにも同じ手順を追加しています。

## 形式と注意点

- 位相列を使用せず、振幅だけを対数周波数で補間します。入力範囲外の差分は0 dBです。時間整合のディレイ値を変更しません。
- 実測差分を作る前に、距離による全体レベル差を除いてください。試聴位置の測定を設計入力にも使う場合は、同じ補正を重ねないでください。
- 深い干渉ディップの逆補正量は自動制限しません。差分ファイル側で補正帯域・平滑化・上限を決め、出力の余裕を確認してください。
- マイク測定、2本の応答からの差分生成、空間平均、ゲート時間の自動設定を追加したものではありません。ゲート時間はIRを見てユーザーが設定します。

## 確認範囲と更新

数値試験と隔離した実アプリで、符号、ON/OFF、主ターゲットの保持、読み込み・保存復帰を確認しています。機材での再生と会場の音響効果は未確認です。実際に使うマイク・出力機器と外部DSPで事前に再測定してください。

作業設定を保存し、[インストールガイド](installation.md)に従って更新した後、PhaseEQを再起動してください。
