# PhaseEQ v2.0.2 更新案内

PhaseEQ v2.0.2では、REWのIIRファイル入出力を拡張し、REWから保存したCamillaDSP用YAMLの読み込みを追加しました。マルチウェイのCamillaDSP出力を独立モジュールへ分離し、互換性と境界条件の不具合を修正しました。

## REW IIRの読み込みと出力

`IIR EQ → REW IIRの読み込み`で、REW Genericの`.txt`、またはCamillaDSP用の`.yml`／`.yaml`を選びます。プレビューを確認し、`IIRを末尾へ追加`を押します。既存のIIRを保持し、手動IIRとして追加します。

- Generic TXTはPEQ、High／Low Shelf、HP／LP、2次All Passに対応します。
- HP／LPは対応する高次フィルターを1次／2次段へ展開して出力します。8次も4次以下の段の組み合わせで表現し、現在の編集上限は8次です。
- 出力できない項目は除外し、対応する項目だけを`REW IIR (.txt)`へ保存します。全項目の成否と除外理由は、別の`REW IIR 出力結果 (.csv)`で確認できます。
- 通常の1次APと極性反転付き1次APの選択名を明確にしました。REW Generic互換を優先し、両者はTXTから除外します。係数を保持して渡す場合はBiquad出力を使用してください。

CamillaDSP YAMLの読み込みは、単一チャンネルのパラメータ形式が対象です。標準`AllpassFO`は通常の1次APとして読み込みます。機器設定を含む構成、複数経路、係数形式は読み込み対象外です。不正・未対応の項目を含む入力は全体を追加せず、設定を保持します。

PEQ・Shelf・All PassのQは既存の0.1刻みに丸めます。高次フィルターの再読み込みでは各段が独立した手動IIRとなります。対応する種類・範囲と再現上の制限は[出力ファイル仕様](output-format.md#rew-peqテキスト)を参照してください。

## マルチウェイのCamillaDSP出力

音声形式名を`F32_LE`へ修正しました。Mute・無効ルート・未接続出力の無音化、入力チャンネル数、物理出力番号の欠番、長いDelayの小数サンプル部分、名前変換後の衝突を修正しました。空のFIRや非有限値など、出力できない設定の事前検証も追加しました。

確定済み係数の生成・保存モデルと各経路の段順を維持しています。Canonical出力はStdin／Stdoutを含む構成、DSP System側は機器設定を別途必要とするsnippetです。実際の音声機器で使う場合は`devices`を設定し、`camilladsp --check`で確認してください。

Canonicalの小数サンプルDelayはCamillaDSPのAP近似です。高域では理想的な時間シフトとの差が生じる場合があります。CamillaDSP 4.1.3では0.1 samples未満を無視します。DSP System側は従来どおり整数サンプルへ丸めます。

## 確認した範囲

REW V5.40 Beta 151の別起動GUIから実際に保存したTXT／YAMLを使い、隔離したPhaseEQの日英画面で読み込み・再出力を確認しました。CamillaDSP 4.1.3では、62種類のIIR定義、FIR ON／OFF、44.1／48／96／192 kHzを両出力経路で処理し、参照応答と照合しました。Mute、未接続、名前衝突、長いFIR、小数サンプルDelayも確認しています。

外部音声機器での再生・音響測定は今回の確認に含みません。使用時は対象環境でのルーティング、各設定値と実現応答を確認してください。
