# PhaseEQ v2.0.3 更新案内

PhaseEQ v2.0.3では、PhaseEQから出力したCamillaDSPのDiffEq／Free係数形式を読み込めるようにしました。既存の読み込み・プレビュー・末尾追加の操作を使用します。

## 係数形式の読み込みと再出力

元のファイルとPhaseEQのFsを合わせ、`IIR EQ → REW IIRの読み込み`で`.yml`／`.yaml`を選びます。プレビューを確認し、`IIRを末尾へ追加`を押してください。

- DiffEqの`a`／`b`配列と、Biquad Freeの係数を読み込みます。各段は0〜2次が対象です。高次フィルターは2次以下の複数段として扱います。
- 読み込んだ段は`Biquad係数`として保存します。周波数・Qへの推定変換を行わず、Gain／Phaseの両画面でON／OFF・複製・削除ができます。係数の直接編集はできません。
- `CamillaDSP`ボタンからDiffEq形式で再出力します。Freeとして読み込んだ係数もDiffEqとして出力します。
- REW TXTでは係数項目を除外します。除外理由は`REW IIR 出力結果 (.csv)`で確認できます。

## Fsと入力の制限

新しいStandalone出力とマルチウェイの分離IIR YAMLにはFsコメントを記録し、読み込み時の不一致を検出します。Fs情報のない既存ファイルは、元のFsを確認してから読み込んでください。取り込み後にFsを変えると、有効な不一致係数の処理を停止します。元のFsへ戻すか、該当項目をOFFにしてください。

非有限値、a0=0、不安定な極、3次以上の単独DiffEq定義は読み込みません。機器設定や複数経路を含む全体構成は対象外です。一件でも不正・未対応の項目がある場合は、全体を追加せず既存設定を保持します。係数項目を保存した設定は、対応版のPhaseEQで使用してください。

詳細は[出力ファイル仕様](output-format.md#camilladsp用yamlの読み込み)を参照してください。

## 確認した範囲

隔離したPhaseEQ画面で、DiffEq／Free各11段の読み込み、既存IIRの保持、ON／OFF、設定保存からの復元、再出力、不正ファイル拒否を確認しました。インストール済みCamillaDSP 4.1.3で元ファイルと再出力を処理し、参照計算との最大サンプル誤差は約2.9×10⁻¹⁴でした。音声機器での再生・音響測定は今回の確認に含みません。
