# PhaseEQ v2.0.8 更新案内

PhaseEQ v2.0.8では、「ルームEQ差分」の表示名を「室内音響補正（ルームEQ）」へ変更し、REWで補正カーブを生成する手順をヘルプとマニュアルへ追加しました。Free／Proの両版に適用します。

## 表示名と操作

`音の補正・フィルター設計 > 目標特性`の`室内音響補正（ルームEQ）`で、`補正カーブを読み込む`、`室内音響補正を適用`、`補正カーブの適用方向`、`補正カーブを保存`、`補正カーブを解除`を操作します。床・壁などの反射による試聴位置の周波数特性の変化を、主ターゲットとは別の補正カーブで扱う機能です。

既存の`room_eq.json`と作業設定はそのまま使用できます。加算／減算、ON/OFF、設定の所有者と復帰、計算順序、主ターゲットと補正カーブの保存分離は維持しています。補正は振幅へ適用し、位相・時間基準を変更しません。

## REWでの生成手順

`REWで補正カーブを作る`を開くと、1m基準と3〜6mの試聴位置測定、耳の高さへのマイク設置、ゲートの扱い、`Align SPL...`、`RMS average`、`A / B`による加算用カーブの生成、補正量の調整、適用後の再測定を確認できます。日本語・英語の両表示に対応しています。

詳しい条件は[室内音響補正の操作手順](room-eq.md)を参照してください。画像付き詳細マニュアル（104ページ・改訂55）と簡易版（15ページ）も更新しました。

差分生成・空間平均・平滑化・補正量の上限制限は外部で行います。カーブを読み込み、目標へ適用した後は必要なEQを更新・出力してください。

## 確認範囲と更新

隔離した実アプリで、日英の名称とヘルプ、既存ファイルの読込み、ON/OFF、加算／減算、専用JSON往復、不正入力時の保持、再読込、Standalone／Way切替を確認しています。数値計算・保存形式のコードは変更していません。REW本体での実測・演算と会場の音響効果は今回未検証です。実際の機材で測定・出力した後は、同じ試聴位置で補正前後を比較してください。

作業設定を保存し、アプリを終了してから[インストールガイド](installation.md)に従って更新・再起動してください。
