# PhaseEQ v2.0.12 更新案内

PhaseEQ v2.0.12では、マルチウェイ測定計画と詳細測定で重複する操作欄を整理し、年末例会の実演資料を更新しました。測定機能はFree／Proで共通です。使用できるマルチウェイ構成は各版の対応範囲に従います。

## 計画の設定を使って測定する

「この構成をマイク測定」から計画を作ると、詳細測定側の方式、時間基準方式・役割・セッション・基準の再選択、保存対象・用途の入力欄を省略します。対象と用途は計画から取得し、旧入力欄に残っている値で上書きしません。基準ツイーター→各ウェイ→次の側の順に進む操作は維持します。

入力機器、個体校正、内部PGAとOS入力ゲイン、ESSとmanifest、保護・出力経路、ゲートは測定前に確認してください。計画を閉じると、単独の詳細測定の操作欄を使用できます。合成・客席の測点保存にはガイド測定を使用します。収録・解析・応答キャッシュと既存の受け渡しを再利用し、計画値の投影を独立した処理へ集約しています。

保存原本は測定ライブラリへ、FRDはHz・dB・位相度の3列で指定フォルダーへ保存します。物理出力の切替と外部プレーヤーの停止は手動です。左右別基準は各側のユニット間に使用し、左右間の到達差と共有SUBをまたぐ整合には別の共通時間基準が必要です。時間基準の由来は原本に保持するため、FRD単体の再読込みでは同じ時間差契約を引き継ぎません。

操作は[マルチウェイ構成からマイク測定する](multiway-microphone-measurement.md)を参照してください。

## 年末例会の資料を更新

デモアジェンダ（3ページ）、配布資料（3ページ）、事前確認チェックリスト（8ページ）をv2.0.12に合わせて更新しました。時間配分・担当・記録欄を保持し、REWへの代替切替を独立した確認工程として追加しています。一般配布ZIPには[配布資料](manual/PhaseEQ_YearEndDemo_Handout_JA.pdf)を収録します。

主手順は、構成保存→計画→基準ツイーターと各ウェイの測定・保存→割り当て・時間整合→外部DSP反映→1m合成・各席の測点保存→補正生成→再出力・再測定です。同じ側のユニット測定では、ウーファーとツイーターの中心間の中点の正面1mにマイクを固定します。ゲートはIRを確認して設定し、客席3〜6mでは反射を含む応答を使います。補正生成へのFRD選択は手動です。

実機でPhaseEQ収録が成立しない場合は、停止・機器解放後に事前確認済みのREWへ切り替えます。個体校正・音響タイミング基準・別クロック補正を確認して測定し、元MDATと応答を保存してPhaseEQへ読み込みます。REWでも成立しない場合は、条件を明示した保存測定で説明します。室内音響補正の操作は[ルームEQの手順](room-eq.md)を参照してください。

目標カーブのON/OFF後は、各状態のEQを再設計・出力し、外部DSPの対応設定で比較します。画面上の切替だけで再生音が切り替わるとは扱いません。既存の画像付き操作マニュアルはv2.0.10・改訂57の撮影内容を保持し、新しい測定操作は上記の手順書と配布資料で補足します。

## 検証と実機での未確認事項

通常の軽量品質チェックは4,181件成功、4件スキップでした。隔離Chromiumで計画中の重複欄の省略、タブ往復、計画終了・再開と次対象への操作を確認しました。合成IRでは、旧入力欄に異なる値を残しても計画の左右・用途で原本4件・FRD4件が保存され、応答の再読込みが一致すること、単独測定の保存欄へ戻れることを確認しました。印刷用PDFは全14ページを描画し、日本語・改ページ・表の見切れを確認しました。

これらはソフトウェア試験です。実機のLinux／Windows 11、UMIK-2のPGA・OS入力ゲイン・SPL精度、DAC/DSPの実配線・保護、時間差精度、ホールでの再生は未確認です。本番前に使用機材で、基準取得→各ウェイ→左右→原本／FRD保存→割り当て・受信・再計算→DSP反映→再測定を通してください。ゲイン確認・保護・時間基準の不成立を迂回せず、確認済みREW／保存測定へ切り替えてください。安全な再生経路が成立しなければ音出しを中止します。

作業設定を保存し、アプリを終了してから[インストールガイド](installation.md)に従って更新・再起動してください。
