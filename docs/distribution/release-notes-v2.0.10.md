# PhaseEQ v2.0.10 更新案内

PhaseEQ v2.0.10では、ガイド測定に測点ごとの自動保存を追加し、Linux／Windows 11のOS入力ゲイン読取りと、UMIK-2の内部PGA確認を整備しました。Free／Proで共通の測定機能です。

## 1m基準から各試聴位置を取得する

ガイドの準備画面で「測点ごとに自動保存する」をONにし、保存フォルダー、ファイル名の先頭文字列、測点名、実距離、保存する応答を設定します。同じ条件で品質を満たす3回を統合して収録を停止し、測定ライブラリと校正済みFRDを各1件保存します。ファイル名は`先頭文字列_YYYYMMDD_HHMMSS.frd`で、収録終了時刻の秒までを自動付与します。同名の別データを上書きしません。

1m基準はウーファーとツイーターの中心を通る測定軸にカプセルを置き、ゲート時間を設定します。試聴位置は着座時の耳の高さで測り、反射を含む応答を使います。外部プレーヤーを止めてからマイクを移動し、「マイクを移動して次の測点を準備」で測点名を入力して開始してください。左右は個別に測定します。自動保存をOFFにすると従来の手動保存を使用できます。

FRDはHz・dB・位相度の3列です。室内音響補正の「作成・評価（試用）」ではHz・dBを使用します。近接合成と、別測定間の共通時間基準に基づくユニット間の自動ディレイ設定は今回の対象に含めません。詳細は[利用ガイド](user-guide.md)を参照してください。画像付き操作マニュアルも110ページ・改訂57へ更新しました。

## Linux／Windows 11の対応条件

OS入力ゲインの読取りを独立モジュールへ分離しました。LinuxはALSAの`(hw:CARD,DEVICE)`付き直接入力と単一のcapture-volume、Windows 11は一意に特定できるハードウェア音量対応の録音デバイスが対象です。両経路は読取り専用です。PulseAudio／PipeWire／default等の仮想入力、Windowsのソフトウェア音量だけの経路は対象外です。ASIO経路との同一性は実機受入れを行っていません。

OSゲインを取得できない場合はメーカーSPL校正・ガイド開始を成立させません。準備後から開始までのゲイン変更・切断を再確認し、収録中は変更境界のSweepを除外して既存のPilot再確認へ戻ります。OS・ドライバーの自動音量調整と音声強調をOFFにしてください。

## UMIK-2の内部PGAをOS入力音量と分ける

UMIK-2は`UMIK-2`や`Microphone Array (UMIK-2)`などGain表記のない入力名を使用できます。校正ファイルのAGainは校正時の内部PGAです。現在のPGAは自動取得せず、メーカーの設定ツール、または校正時から変更していないことが分かる設定履歴で一致を確認してチェックします。不明な場合はチェックせず、設定を確認してください。

内部PGAは収録中に変更しないでください。変更後は停止して対応する校正ファイルを登録し、準備からやり直します。機器・個体・校正内容・入力chの変更時は確認を解除します。確認の由来を測定原本へ保存し、AGainを現在PGAの自動観測値として扱いません。UMIK-1の従来の照合は維持します。

## 確認範囲と事前確認

関連テストと通常の軽量品質チェック、合成入力による隔離Chromiumでの測点保存・PGA確認を検証しました。実機マイクの収録、Linux／Windows 11のネイティブAPIとドライバー、UMIK-2のPGA設定・SPL精度、4ch出力と会場再生は未確認です。

実演機では、入力ゲインのdB値と変更追従、ミュート・切断時の採用停止、1mと各試聴位置の取得、FRD保存、室内音響補正への読込み、出力ch対応と再生を事前に確認してください。保存失敗時は結果を保持して別フォルダーへ再試行できます。DB原本を先に保存した場合はその原本を保持します。外部プレーヤーの停止は手動です。実機受入れが完了していない構成では、事前確認済みのREW測定・読込みを使用してください。

作業設定を保存し、アプリを終了してから[インストールガイド](installation.md)に従って更新・再起動してください。
