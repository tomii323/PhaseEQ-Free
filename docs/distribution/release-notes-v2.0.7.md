# PhaseEQ v2.0.7 更新案内

PhaseEQ v2.0.7では、起動前の環境チェック、PhaseEQ、マルチウェイでフォントキャッシュの保存先を共通化しました。Free／Proの両版に適用します。

## 変更内容

- OS標準のユーザーキャッシュ領域に保存し、別プロセスや次回起動でも同じフォント一覧を再利用します。
- 保存先の選択を独立した共通モジュールに集約しました。依存確認・修復・アプリ起動の順序と、グラフ・EQ計算の処理は変更していません。
- `MPLCONFIGDIR`に保存先を指定している場合は、その指定を優先します。検証用の一時キャッシュも従来どおり分離します。

## 更新後の初回起動

作業設定を保存し、アプリを終了してから[インストールガイド](installation.md)に従って更新・再起動してください。新しい保存先で初めてフォント一覧を生成する際は、`Matplotlib is building the font cache; this may take a moment.`と表示される場合があります。完了まで待ってください。

旧キャッシュの移動・削除は行いません。毎回通知が出る場合は、保存先への書込み権限とキャッシュを削除する設定を確認してください。フォントやMatplotlibの変更でも再生成される場合があります。標準の保存先は[フォントキャッシュの案内](installation.md#フォントキャッシュ生成の通知が表示される)を参照してください。

画面の操作手順は従来と同じです。同梱の画像付きマニュアルはv2.0.6版を継続して使用できます。

## 確認範囲

macOS／Python 3.13の専用領域で、別プロセス間のキャッシュ再利用と、フォント一覧の内容・更新時刻の保持を確認しました。Windows／Linuxの保存先選択は模擬試験で確認しています。Windows／Linuxでの実機起動は未実施です。更新後は通常起動とグラフ表示を確認してください。
